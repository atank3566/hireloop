# intake — 입력 모달리티 무관 추출

화면정의서는 **엑셀 / 표 / 자유 텍스트 / 캡처본(이미지) / 한 줄 요청** 어떤 형태로도 온다. 형식에 단정짓지 말 것. 목표는 형식이 아니라 거기서 **공통 필드 목록**을 뽑는 것이다.

## 모달리티별 읽는 법

| 모달리티 | 방법 |
|---|---|
| 캡처/이미지 | `Read` 로 이미지를 직접 본다 — 레이아웃·라벨·반복 블록·입력칸을 눈으로 읽어 필드/마스터-디테일을 추출 |
| 엑셀(.xlsx) | 시트를 텍스트로 덤프해 표를 읽는다. 아래 "관찰된 엑셀 형태" 참고 (강제 아님) |
| 표/마크다운 | 컬럼 헤더에서 항목명·컨트롤·설명을 매핑 |
| 자유 텍스트 | 문장에서 항목·동작·반복("~목록", "~별로")·선택지를 식별 |
| 한 줄 요청 | 추출할 게 거의 없음 → `routing.md` 의 "구조 미제공" 경로로 |

## 추출 결과 = 모달리티 무관 필드 목록

각 항목을 다음으로 정규화한다 (없으면 비움 → 후속 단계가 추론):

- `name` — 항목명 (예: 거래처, Lot No, 수량)
- `intent` — 입력 의도: 표시 / 선택 / 날짜 / 코드도움 / 숫자 / 텍스트 / 반복목록 중 하나 (의도→컨트롤은 `conventions.md`)
- `section` — master / detail (또는 미상)
- `visible` — 표시 / 숨김 / 강조(중요)
- `usage` — 저장·수정 / 조회조건 / 표시전용 등 (있으면)
- `default` — 기본값 단서 (예: "현재일 -1month", "특정 고정값 디폴트")
- `note` — 동작/통제 설명 원문

## 관찰된 엑셀 형태 (부록 — 만나면 쓰는 힌트, 강제 아님)

단일 시트, 헤더 + 두 섹션 표로 오는 경우가 많다:

- 헤더 행: `프로그램명` · `화면구분`(입력 / 조회(일반)) · `개발개요` · `화면명` · `이벤트`(저장/삭제/신규/조회)
- `Master` 표: `항목사용여부 | 항목명 | 컨트롤타입 | 항목설명 | (용도)`
- `Detail(품목정보)` 표: 동일 5컬럼
- `추가공유내용`: 버튼 동작·통제 로직 자유 서술

규칙:
- `항목사용여부` = `숨김` → **노드 생성 제외**(저장 시 시스템이 채우는 키일 때가 많음 — 채번/현재일/로그인부서 등). `중요` → 강조 스타일. `표시` → 일반.
- 마지막 컬럼 의미는 화면구분에 따라 다름: 입력=`저장/수정`, 조회 Master=`조회조건`, 조회 Detail=`조회여부`.
- `항목설명` 에 기본값 단서·연결 로직(원천 화면 조회 등)이 들어있다 → `default`/`note` 로 옮긴다.

> `컨트롤타입` 표기(label/ComboBox/DateBox/Codehelp/FloatBox/TextBox …)가 **명시되면 그대로 직역**한다 — `conventions.md` §1 "직역(고정 매핑)" 표. 항목설명의 "조회/원천/참조" 단어에 휘둘려 `label`→`Search` 같이 바꾸지 말 것(대표 오매핑). 표기가 없을 때만 `intent` 로 추론한다.
